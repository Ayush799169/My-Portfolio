
# 💼 Ayush Yadav - Personal Portfolio

A modern and fully responsive developer portfolio built using React.js, Vite and Tailwind CSS.
This portfolio showcases my skills, projects, certificates, resume, gallery, and contact information in a clean and interactive UI.

## ✨ Features

- Responsive Design
- Modern UI
- Smooth Scrolling Navigation
- Animated Sections (AOS)
- Typing Animation
- Skills Showcase
- Projects Section
- Certificates Section
- Gallery
- Blog Section
- Resume Download
- Contact Form
- Social Media Links
- Mobile Friendly
- Fast Performance
